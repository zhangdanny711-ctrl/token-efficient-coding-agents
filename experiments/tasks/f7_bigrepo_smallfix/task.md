# Task: product slugs keep a trailing hyphen

## Goal
URL slugs generated by the storefront must never start or end with a
hyphen. `slugify("!!hello!!")` must return `"hello"`.

## Current behavior
Slugs generated from names with trailing punctuation come out with a
dangling hyphen, e.g. `"deluxe-espresso-machine-"`.

`python3 -m pytest tests/ -q` reproduces the problem (2 failures).

## Acceptance
All tests under `tests/` pass.

## Scope
Fix the `storefront/` package. Do not modify the tests.
